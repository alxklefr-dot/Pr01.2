# SYSTEM HANDOVER: CONTENT GENERATION ENGINE FOR LANGSIFT ## 1. BACKGROUND & OVERVIEW LangSift is a lightweight, mobile-responsive web application designed to help English speakers learn French through level-adaptive reading. The app relies on a single HTML file containing an embedded JavaScript database (`db`) and a flat vocabulary mapping dictionary (`dictionary`). ## 2. DATABASE ARCHITECTURE REQUIRMENTS When generating content (either a 'story' or a 'news' article), you must provide the output structured exactly as a JavaScript object entry. Each item must contain text variants mapped precisely across 5 CEFR-aligned difficulty levels: - **A1:** Extremely simple sentences, heavy repetition, core vocabulary. Only a selected few target vocabulary words should be wrapped in `` tags. - **A2:** Slightly longer sentences, introduction of common past tenses (passé composé). - **B1:** Paragraph structure, narrative flow, more diverse vocabulary, standard descriptive tenses (imparfait). - **C1:** Advanced syntax, complex conjunctions, nuanced vocabulary, idiomatic expressions. - **Fluide:** Native-level French, rich literary or advanced journalistic phrasing, complex tenses (subjonctif, passé simple where appropriate). - **Eng_A1 to Eng_Fluide:** Natural English translations of each respective level. ## 3. TEXT TAGGING & DICTIONARY FORMATTING RULES To make words interactive (clickable for flashcards), specific French vocabulary words must be tagged in the database strings, and their literal definitions added to the dictionary. - **In the Text:** Wrap the target French word EXACTLY like this: mot. - **Linguistic Cleanliness:** Do NOT include punctuation inside the `` tag. (e.g., Use `un garçon...` NOT `un garçon.`). - **In the Dictionary Object:** Every single word you choose to put in a `` tag MUST have a corresponding key-value entry generated for the `dictionary` object. - **Format:** All keys must be lowercase, stripped of punctuation, and mapped to a concise English translation string. - **CRITICAL SYNTAX WARNING:** Keys and values must be separated by a COLON (`:`), never a comma (`,`). An incorrect comma inside the object declaration will crash the browser DOM parsing engine. ## 4. EXPECTED OUTPUT TEMPLATE When asked to create a story or news piece, output it exactly in this code block template: ### CODE TO PASTE INTO THE 'DB' OBJECT: [id_number]: { title: "[Title in French]", A1: `[French A1 text with selective bold words]`, A2: `[French A2 text]`, B1: `[French B1 text]`, C1: `[French C1 text]`, Fluide: `[French Fluide text]`, Eng_A1: "[English Translation]", Eng_A2: "[English Translation]", Eng_B1: "[English Translation]", Eng_C1: "[English Translation]", Eng_Fluide: "[English Translation]" } ### CODE TO ADD TO THE 'DICTIONARY' OBJECT: "word1": "translation1", "word2": "translation2", "word3": "translation3"
